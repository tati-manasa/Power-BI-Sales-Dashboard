# 📊 Power BI Sales Dashboard

## 📌 Project Overview
This project presents an interactive Sales Dashboard developed using Microsoft Power BI. It provides meaningful insights into sales performance, profit, quantity, product categories, and payment methods through dynamic visualizations and KPI cards.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Track total sales and total profit.
- Monitor total quantity sold.
- Compare sales across different product categories.
- Analyze sales by payment mode and sales type.
- Understand monthly and daily sales trends.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Quantity
- Total Profit
- Profit Percentage

## 📊 Dashboard Features
- Interactive KPI cards.
- Monthly Sales and Profit Analysis.
- Sales by Product.
- Sales by Category.
- Sales by Payment Mode.
- Sales by Sale Type.
- Daily Sales Trend.
- Interactive slicers and filters.

## 📂 Project Files
- `Sales_Dashboard_PowerBI.pbix` – Power BI dashboard file.
- `Dashboard_Screenshot.png` – Dashboard preview.

## 💡 Key Learnings
- Data cleaning and transformation.
- Creating calculated columns and DAX measures.
- Designing interactive dashboards.
- Building meaningful business insights using Power BI.
